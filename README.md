# Exercícios de Aprendizado de Máquina

Repositório com notebooks e exercícios de **Machine Learning** utilizando Python e Scikit-learn.

## Conteúdo

* `6-amostragem e divisão de dados.ipynb`
  Separação de treino e teste, validação e amostragem de dados.

* `7-fluxo de trabalho automático.ipynb`
  Pipelines e automação de etapas do modelo.

* `8-avaliação de modelos preditivos.ipynb`
  Métricas de avaliação, matriz de confusão e validação cruzada.

* `9-métodos probabilísticos.ipynb`
  Algoritmos probabilísticos como Naive Bayes.

* `10-métodos baseados em árvores.ipynb`
  Árvores de decisão, Random Forest e Gradient Boosting.

## Tecnologias

* Python
* Jupyter Notebook
* Scikit-learn
* Pandas
* NumPy
* Matplotlib
